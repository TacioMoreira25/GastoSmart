Sistema de controle de despesas estruturado em Clean Architecture com .NET. O projeto possui um backend em ASP.NET Core (GastoSmart.Api), persistência com Entity Framework Core e banco de dados (GastoSmart.Infrastructure), regras de negócio isoladas (GastoSmart.Domain e Application) e um aplicativo cliente feito em .NET MAUI (GastoSmart.App) que consome a API. O sistema inclui análise de recibos usando serviços de IA (GroqReceiptAnalyzerService) e OCR com Tesseract.
